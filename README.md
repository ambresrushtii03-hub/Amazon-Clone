# Amazon-Clone

🌐 Live Demo:
https://amazon-clone-two-ashen.vercel.app/

A responsive front-end clone of the Amazon homepage built using HTML and CSS. This project replicates the basic layout and design of Amazon, including the navigation bar, product sections, banners, and footer. It was created to practice modern web design, layout structuring, and responsive styling techniques.
🚀 Features
Responsive Amazon-inspired homepage
Navigation bar with search section
Product category cards
Hero banner section
Footer with multiple links
Clean and organized UI design
🔗 Future Improvements
Add JavaScript functionality
Implement responsive mobile menu
Add product sliders and animations
Integrate backend and authentication
